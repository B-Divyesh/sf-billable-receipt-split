## Release decision

**FAIL — S1 release blocker: the production server-side license endpoint has no observable rate limit.**

The work order requires every server-side endpoint, including the product-unlock API, to return `429` with `Retry-After` under a rapid burst. The only application server-side operation is the Sociobot license API. Fresh invalid-token bursts against the exact production endpoint produced only successful responses:

```text
GET https://api.sociobot.in/api/v1/products/billable-receipt-split/verify?license=qa-rate-limit-invalid

80 requests, 20 concurrent:  80 × HTTP 200
200 requests, 40 concurrent: 200 × HTTP 200
```

No `429` response and no `Retry-After` header were observed; therefore no threshold can be recorded. This is a release blocker against the explicit acceptance contract. The endpoint should rate-limit unauthenticated verification attempts and return a meaningful `Retry-After` value. It is a production Sociobot API responsibility, not repository product-code work permitted to this verifier.
